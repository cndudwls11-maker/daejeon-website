# 🌆 대전광역시 홈페이지

대전광역시를 소개하는 반응형 원페이지 웹사이트입니다.

## 📋 페이지 섹션

| 섹션 | 설명 |
|------|------|
| **Hero (홈)** | 대전광역시 소개 타이틀, 과학·교육·휴양 도시 뱃지 |
| **대전 소개** | 위치, 인구, 과학·연구, 행정, 스포츠, 자매도시 정보 카드 |
| **Stats** | 국책연구기관, 대학교, KTX 역사, 공원·박물관 숫자 카운터 |
| **명소** | 계족산 황톳길, 국립중앙과학관, 대전 오월드, 보문산성, 둔산동·은행동, 식장산 전망대 |
| **맛집** | 성심당, 대전 칼국수, 떡볶이 골목, 대청호 회 |
| **갤러리** | 대전 명소 이미지 그리드 (클릭 시 라이트박스) |
| **문의** | 이름/이메일/내용 연락처 폼 |
| **Footer** | 바로가기 링크, SNS 아이콘, 연락처 정보 |

## 🛠 기술 스택

- HTML5
- CSS3 (반응형 디자인, Flexbox, Grid)
- JavaScript (Vanilla JS)
- AOS (Animate On Scroll)
- Font Awesome
- Google Fonts (Noto Sans KR)

## 🚀 실행 방법

`index.html` 파일을 브라우저로 열면 됩니다.

## 📂 파일 구조

```
├── index.html      # 메인 페이지
├── style.css       # 스타일시트
├── script.js       # 자바스크립트
├── robots.txt      # 검색 엔진 크롤링 설정
├── sitemap.xml     # 사이트맵
└── README.md       # 프로젝트 설명
```
